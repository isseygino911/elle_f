# Arco — 主管手册

*身份：**主管**。你以数据的形式了解机构的运营情况。*

> English version: [../03-manager.md](../03-manager.md)

这是一本很短的手册，而这正是重点。你的身份只有一个真正重要的界面，对其余一切的视野都被刻意收窄。

---

## 1. 请先读这一条规则

**主管不是"高级教师"。**

人们往往以为主管是权限最大的身份——在其他软件里通常确实如此。但在 Arco 中并非如此。主管看到的**比教师更少**，这是刻意为之。

你可以看到上了多少节课、有多少活跃学生、每位教师的工作量情况。你**永远不能**打开某个学生的视频、阅读消息，或查看某人作业的正文。

> 可以这样理解：主管看到的是**记分牌**，不是**比赛本身**。

这不是把界面藏起来而已。该限制由服务端强制执行：即使你直接输入某个学生页面的地址，数据也不会被返回。

## 2. 登录

机构所有者会发给你一个邀请链接——只有所有者才能创建主管。打开链接，设置姓名、邮箱和密码，然后登录。

![接受邀请](../screenshots/shared-01-accept-invite-register.jpg)

## 3. 你的仪表盘

这是你的主界面，也几乎是你唯一的界面。

![主管仪表盘](../screenshots/manager-01-dashboard.jpg)

### 四个计数

| 计数 | 统计内容 |
|---|---|
| **教师** | 机构内的教师人数。 |
| **学生** | 所有教师名下的学生总数。 |
| **即将开始的课程** | 已预约且尚未发生的课程。 |
| **待审阅视频** | 等待教师给出评语的学生视频。 |

*待审阅视频*是最值得关注的一项。如果这个数字逐周攀升，说明作业提交的速度快于教师处理的速度。

### 任务进度

机构共享待办清单的完成百分比——已完成多少项、还有多少项未完成。你只能看到进度条，看不到具体的任务内容。

### 按教师

每位教师一行：**学生**、**即将开始**、**已完成**、**待审阅视频**、**未读**。

这是你的工作量视图。它能回答"有没有人超负荷？有没有人在评语上落后？"，同时不暴露任何一位学生的作业。

> 请注意这张表包含什么：教师姓名和统计数字。**你的仪表盘上任何地方都不会出现学生姓名**——不在表格中，不在表格背后，也不在浏览器收到的底层数据里。

---

## 4. 公告

**侧边栏 → 公告（02）。** 你唯一的另一个板块。

你可以看到机构内发出的每一条公告——由所有者和每位教师发送的——包括发送人、接收对象，以及覆盖了多少人。

![主管视角的公告](../screenshots/manager-03-announcement-redacted.jpg)

你**看不到**的是消息正文本身。在本该显示正文的位置，Arco 会写道：

> *你可以看到公告已发送及其覆盖人数。消息正文仅在发送者与其学生之间可见。*

**送达情况**面板仍会提供有用的部分：接收人数、接收对象、发送人和时间。

你不能发送公告。主管界面上没有*发布*按钮——那属于所有者和教师。

---

## 5. 通知

姓名上方的铃铛图标会以同样的详略程度呈现机构事件——例如*"公告已发送给 1 位学生"*，包含标题和发送人，但永远不含正文。

![通知](../screenshots/manager-04-notifications.jpg)

**标为已读**清除一条；**全部标为已读**清除全部。

---

## 6. 你无法访问的内容

如果你点击链接或直接输入超出你身份范围的地址，Arco 会明确提示，而不是显示一个坏掉的页面：

![无访问权限](../screenshots/manager-02-no-access.jpg)

| 板块 | 主管的访问权限 |
|---|---|
| 仪表盘 | ✅ 仅汇总数据 |
| 公告 | ✅ 元信息与送达数据，永远不含正文 |
| 通知 | ✅ 事件与统计 |
| 资料库 | ✅ 机构共享文件（见下） |
| 学生 | ❌ 无访问权限 |
| 课程与作业 | ❌ 无访问权限 |
| 视频 | ❌ 无访问权限 |
| 消息 | ❌ 无访问权限 |
| 预约 | ❌ 无访问权限 |
| 邀请 | ❌ 无访问权限 |
| 机构设置 | ❌ 仅所有者 |

### 唯一的例外：资料库

共享资料库——讲义、乐谱、机构文件——机构内所有人都可以阅读，主管也不例外。它不在你的侧边栏中，但也没有被拦截。

这是刻意的区分，而非疏漏。资料库存放的是机构面向所有人发布的材料，从不存放某位学生的作业。学生本人的提交、视频和消息，对你始终是关闭的。

---

## 7. 日常功能

- **语言** — 点击侧边栏底部的姓名，在**English**和**中文**之间切换。
- **退出登录** — 同一菜单。

---

## 该看什么，什么时候看

- **每周：** 各教师的*待审阅视频*。数字上升是评语进度开始滞后的最早信号。
- **每周：** 各教师的*未读*——学生的消息无人回复。
- **每月：** 各教师的*学生*人数，用于评估全机构的工作量是否均衡。
- **持续关注：** *任务进度*，判断机构的行政事务是否真的在推进。

如果某个数字让你对某位具体的学生产生疑问，这个问题应该交给所有者或教师。按照设计，你无法在这里得到答案。
